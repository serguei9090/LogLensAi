# db

## Overview
DuckDB persistence layer managing pooled single-database opening and WAL recovery, DDL schema initialization and 12-step migrations, default settings seeding, batched log ingestion (Appender with transactional fallback), clustering batch updates, cluster triage storage, and DuckDB-VSS HNSW vector setup.

## Interface
- `[db.go:MemoryDB]`: Constant `":memory:"` used when `Open` receives an empty path.
- `[db.go:DB]`, `[db.go:Open]`, `[db.go:DB.Close]`: Pooled `*sql.DB` handle (`Conn`, `Path`), constructor initializing schema/migrations/cluster-cache/default-settings (with one-shot `.wal` recovery retry), and nil-safe closer.
- `[schema.go:AllTables]`: Slice of the 17 core DuckDB tables (`logs`, `ingestion_jobs`, `settings`, `clusters`, `fusion_configs`, `ai_sessions`, `log_streams`, `ai_messages`, `ai_memory`, `temporal_offsets`, `workspace_settings`, `settings_templates`, `anomalies`, `folders`, `log_sources`, `knowledge_documents`, `hourly_cluster_counts`).
- `[clustering_queries.go:UnprocessedLog]`, `[clustering_queries.go:LogUpdate]`, `[clustering_queries.go:ClusterIncrement]`, `[clustering_queries.go:DB.SelectUnprocessedLogs]`, `[clustering_queries.go:DB.CountUnprocessedLogs]`, `[clustering_queries.go:DB.ApplyClusteringBatch]`, `[clustering_queries.go:DB.UpdateIngestionJobProgress]`: Unprocessed log queries, atomic clustering batch application, and ingestion-job progress tracking.
- `[clustering_triage.go:ClusterTriage]`, `[clustering_triage.go:DB.InitClusterTriageTable]`, `[clustering_triage.go:DB.UpsertClusterTriage]`, `[clustering_triage.go:DB.UpsertClusterRAGTag]`, `[clustering_triage.go:DB.GetClusterTriage]`, `[clustering_triage.go:DB.GetClusterTriageMap]`: Cluster triage and RAG match persistence (`cluster_triage`).
- `[ingestion_queries.go:LogStreamConfig]`, `[ingestion_queries.go:LogInsertRow]`, `[ingestion_queries.go:DB.ActiveLogStreams]`, `[ingestion_queries.go:DB.FusionParserConfig]`, `[ingestion_queries.go:DB.FacetExtractionRulesJSON]`, `[ingestion_queries.go:DB.InsertLogBatch]`, `[ingestion_queries.go:DB.InsertLogBatchAppender]`: Ingestion stream/parser/rule lookups and batched log insertion.
- `[vss.go:AIMemoryEmbeddingDim]`, `[vss.go:VSSStatus]`, `[vss.go:SetupVectorSearch]`: 768-dim `ai_memory.embedding` schema guard, `vss` extension loader, and HNSW index setup.

## Invariants
- `[db.go:Open]`, `[db.go:resolvePath]`, `[db.go:openDuckDB]`, `[db.go:recoverWAL]`, `[db.go:DB.init]`: Normalizes `""` to `":memory:"` and file paths via `filepath.Abs`; opens at most one `*DB` per file path so `database/sql` shares a single `duckdb_database` handle; runs `Conn.Ping()` eagerly, retrying once after deleting `<dbPath>.wal` on file-backed DB failures; runs `setupSchema -> runMigrations -> initializeClusterCache -> initializeDefaultSettings` in strict order (closing `Conn` on init failure).
- `[driver_duckdb.go:cgo]`: Imports `github.com/marcboeker/go-duckdb` under `//go:build cgo`.
- `[schema.go:setupSchema]`, `[schema.go:sequenceStatements]`, `[migrations.go:runMigrations]`: Executes idempotent `IF NOT EXISTS` DDL across 5 table sequences (`log_id_seq`, `log_streams_id_seq`, `ai_messages_id_seq`, `settings_templates_id_seq`, `ingestion_jobs_id_seq`), 16 initial tables, and 12 ordered migration steps; `[migrations.go:migrateIngestionColumns]` drops dependent indexes before adding `logs.processed`; `[migrations.go:migrateDrainMasks]` rewrites legacy PCRE lookbehind IP masks and fills missing default mask labels.
- `[clustering_queries.go:DB.SelectUnprocessedLogs]`, `[clustering_queries.go:DB.CountUnprocessedLogs]`: Return empty/zero with `nil` error if `logs` does not exist yet; `SelectUnprocessedLogs` casts `facets` to `VARCHAR`.
- `[clustering_queries.go:DB.ApplyClusteringBatch]`, `[clustering_queries.go:applyLogUpdatesTx]`: Assumes callers serialize invocations (never called concurrently on the same `*DB`); drops all 5 `logsIndexes` in autocommit mode before the transaction and recreates them in a `defer` block; updates `logs.processed = TRUE` while preserving existing `timestamp` via `COALESCE` and recording `hourly_cluster_counts` when `cid` and resolved timestamp are non-NULL.
- `[clustering_queries.go:DB.UpdateIngestionJobProgress]`: Advances only the latest (`ORDER BY created_at DESC LIMIT 1`) `pending`/`processing` job for `(workspaceID, sourceID)` and marks `completed` only when `status = 'processing' AND processed_lines >= total_lines`.
- `[clustering_triage.go:DB.InitClusterTriageTable]`, `[clustering_triage.go:DB.UpsertClusterRAGTag]`, `[clustering_triage.go:DB.GetClusterTriage]`: Keys `cluster_triage` by `(workspace_id, cluster_id)`; `UpsertClusterRAGTag` defaults new rows to `category='application'`, `severity=2.0`, `is_outage=false`, `confidence=0.8` without overwriting non-empty existing templates or triage fields on conflict; `GetClusterTriage` returns `(nil, nil)` on `sql.ErrNoRows`.
- `[ingestion_queries.go:DB.InsertLogBatch]`, `[ingestion_queries.go:DB.InsertLogBatchAppender]`: No-op on empty slices; `InsertLogBatch` falls back to transactional `INSERT` (`insertLogBatchTx`) if the native DuckDB Appender fails; `FusionParserConfig` and `FacetExtractionRulesJSON` treat `sql.ErrNoRows` as empty defaults.
- `[settings.go:initializeDefaultSettings]`: Seeds the 33 default settings rows (including 11 `defaultDrainMasks`) only when `settings` is empty (`COUNT(*) == 0`).
- `[vss.go:SetupVectorSearch]`, `[vss.go:ensureAIMemoryEmbeddingColumn]`, `[vss.go:ensureAIMemoryVectorIndex]`: Fails only if adding `ai_memory.embedding FLOAT[768]` fails; `INSTALL`/`LOAD vss` or HNSW index failures degrade gracefully (`VSSStatus.Degraded = true`).

## Side Effects
- `[db.go:Open]`, `[db.go:recoverWAL]`, `[db.go:DB.Close]`: Opens/creates or closes the DuckDB database and deletes `<dbPath>.wal` on WAL recovery, logging warnings via `log.Printf`.
- `[schema.go:setupSchema]`, `[migrations.go:runMigrations]`, `[clustering_triage.go:DB.InitClusterTriageTable]`, `[settings.go:initializeDefaultSettings]`: Executes DDL (`CREATE SEQUENCE/TABLE/INDEX`, `ALTER TABLE`, `DROP INDEX`), temporary backup table swaps (`fusion_configs_backup`), backfills (`hourly_cluster_counts`, `clusters`), status resets on stale `ingestion_jobs`, and initial `settings` seeding.
- `[clustering_queries.go:DB.ApplyClusteringBatch]`, `[clustering_queries.go:DB.UpdateIngestionJobProgress]`, `[clustering_triage.go:DB.UpsertClusterTriage]`, `[clustering_triage.go:DB.UpsertClusterRAGTag]`, `[ingestion_queries.go:DB.InsertLogBatch]`: Mutates `logs` (including dropping/recreating secondary indexes), `clusters`, `hourly_cluster_counts`, `cluster_triage`, and `ingestion_jobs`, updating `log_id_seq` via `setval` when using the Appender.
- `[vss.go:SetupVectorSearch]`, `[vss.go:loadVSSExtension]`, `[vss.go:ensureAIMemoryVectorIndex]`: May download/install/load DuckDB `vss` (`INSTALL vss; LOAD vss;`), sets `hnsw_enable_experimental_persistence = true`, creates `ai_memory_embedding_idx`, and logs degradation notices via `log.Printf`.
