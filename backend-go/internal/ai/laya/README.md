# laya

## Overview
Local Laya AI System 1 decision engine (`nvkudva/laya-web-q8` ModernBERT ONNX encoder + classification head with optional `MockEngine` fallback), pure-Go WordPiece tokenizer, `[MASK]`-based sequence builder, softmax/rubric decision scoring, Hugging Face model downloader, and versioned checkpoint rule manager.

## Invariants
- `[engine.go:NewONNXEngine]`, `[engine.go:ONNXEngine.SetDevice]`, `[mock_engine.go:MockEngine.SetDevice]`, `[rules.go:RuleManager.UpdateSettings]`: Only `"cpu"` and `"gpu"` devices are accepted (empty defaults to `"cpu"`); `NewONNXEngine` clamps `Temperature <= 0` to `1.0`, `HiddenDim <= 0` to `1024`, and `maxLen` to `8192`, falling back to `LOGLENS_LAYA_ENCODER_PATH`/`LOGLENS_LAYA_HEAD_PATH` when paths are omitted.
- `[engine.go:ONNXEngine.Predict]`, `[engine_nocgo.go:newONNXSessionRunner]`, `[engine_onnx.go:newONNXSessionRunner]`, `[engine_onnx.go:realONNXRunner.RunEncoder]`, `[engine_onnx.go:realONNXRunner.RunHead]`: Serializes inference via `mu`; rejects closed engines or empty `MaskIndices`; real ONNX requires `CGO_ENABLED=1`, encoder tensors `[1, seqLen]` -> `[1, seqLen, hiddenDim]` (`input_ids`/`attention_mask` -> `last_hidden_state`), and head tensors `[numMasks, hiddenDim]` -> `[numMasks, 1]` (`hidden_states` -> `logits`).
- `[sequence.go:SequenceBuilder.BuildSequence]`, `[tokenizer.go:Tokenizer.wordpiece]`: Formats `[clsID] <headerTokens> [sepID] ([maskID] <optTokens>)+ [sepID] <stateTokens> [sepID]`, erroring if header + options exceed `maxLen` and truncating `stateTokens` to fit; pretokens > 100 runes or missing WordPiece subwords map to `[UNK]` (`100`).
- `[decision.go:Softmax]`, `[decision.go:ComputeDecisionResult]`: Clamps `temperature <= 0` to `1.0` and uses max-subtraction before `math.Exp`; `QuestionTypeNoul` sets `SelectedLabel = "true"` iff `probs[0] >= 0.5`; `QuestionTypeScore` computes expected rubric score.
- `[downloader.go:ModelManager.RefreshStatus]`, `[downloader.go:ModelManager.downloadSingleFile]`: Reaches `ModelStateReady` iff all 5 model/tokenizer files exist as non-directories; downloads write `.part` temp files and atomically rename on HTTP 200 completion.
- `[rules.go:RuleManager]`, `[rules.go:RuleManager.SaveCheckpoint]`, `[rules.go:RuleManager.RollbackToCheckpoint]`: Synchronized by `sync.RWMutex`; validates non-empty questions, choice options, and score rubrics; rolls back in-memory mutations if `saveLocked` fails; deep-clones questions/slices; `[types.go:RuleConfig.UnmarshalJSON]` and `[types.go:LayaSettings.UnmarshalJSON]` prefer `active_checkpoint` over `activeCheckpoint`.

## Side Effects
- `[downloader.go:ModelManager.*]`: Stats/creates/deletes `modelDir` and `.part` files on disk, runs background HTTP GET downloads from Hugging Face (or `SetBaseURL`), and invokes `onComplete`.
- `[engine.go:NewONNXEngine]`, `[engine.go:resolveSharedLibPath]`, `[engine_onnx.go:newONNXSessionRunner]`, `[engine_onnx.go:realONNXRunner.*]`: Reads `LOGLENS_LAYA_ENCODER_PATH`, `LOGLENS_LAYA_HEAD_PATH`, and `LOGLENS_ONNXRUNTIME_PATH` env vars, loads tokenizer/model weights from disk, mutates global `onnxruntime_go` state (`SetSharedLibraryPath`, `InitializeEnvironment`), and allocates/destroys native ONNX sessions and tensors (using DirectML device `0` when `"gpu"`).
- `[rules.go:NewRuleManager]`, `[rules.go:RuleManager.*]`: Reads and atomically rewrites `configPath` JSON via `[rules.go:atomicWriteFile]` (temp file, `Sync`, `Close`, `Chmod`, `Rename`), generates UUIDs, and reads `time.Now().UTC()`.
