# rpc

## Overview
JSON-RPC 2.0 transport, validation registry, stub/live method registration, and SSE chat streaming layer. Bridges both newline-delimited `stdin/stdout` and HTTP (`POST /rpc` + `POST /api/stream_chat`) transports to `*app.App`, `*ai.Extra`, and `internal/ai/graph`.

## Interface
- `[registry.go:CodeParseError]`, `[registry.go:CodeInvalidRequest]`, `[registry.go:CodeMethodNotFound]`, `[registry.go:CodeInvalidParams]`, `[registry.go:CodeInternalError]`: JSON-RPC 2.0 error codes (`-32700`, `-32600`, `-32601`, `-32602`, `-32603`).
- `[registry.go:Handler]`, `[registry.go:ParamsFactory]`, `[registry.go:Registry]`, `[registry.go:NewRegistry]`, `[registry.go:Registry.Register]`, `[registry.go:Registry.RegisterWithModel]`, `[registry.go:Registry.Methods]`, `[registry.go:Registry.Has]`, `[registry.go:Registry.Len]`: Method registry mapping RPC method names to handlers and optional parameter validators.
- `[dispatch.go:Registry.Dispatch]`: Validates params (when `ParamsFactory` is attached), invokes the handler with panic recovery, and constructs `models.JSONRPCResponse`.
- `[http.go:NewHTTPHandler]`, `[http.go:ListenAndServe]`: HTTP transport serving `POST /rpc` (with `OPTIONS` CORS preflight).
- `[stdio.go:RunStdio]`: Line-delimited JSON-RPC 2.0 transport over `io.Reader`/`io.Writer`.
- `[methods.go:RegisterStubs]`: Registers 72 baseline stub handlers from `allMethods` (54 using `paramModels` validation and 18 without).
- `[app_methods.go:RegisterApp]`: Registers 22 `*app.App`-backed methods (`get_logs`, `start_tail`, `stop_tail`, `is_tailing`, `ingest_logs`, `ingest_local_file`, `get_clustering_status`, `set_clustering_mode`, `set_clustering_paused`, `get_clusters`, `get_metadata_facets`, `get_log_content`, `get_health`, and 9 `*_laya_*` methods).
- `[ai_methods.go:RegisterAI]`: Registers `send_ai_message` backed by `graph.Run`, `graph.Provider`, and `*graph.ToolRegistry`.
- `[ai_extra_methods.go:RegisterAIExtraMethods]`: Registers 17 AI-extra/dashboard/anomaly/RAG methods (`get_ai_sessions`, `get_ai_messages`, `rename_ai_session`, `delete_ai_session`, `get_ai_mapping`, `get_anomalies`, `get_dashboard_stats`, `analyze_cluster`, `list_ai_models`, `test_ai_connection`, `generate_facet_regex`, `save_memory`, `search_memory`, `sync_knowledge_base`, `get_rag_model_status`, `download_rag_model`, `delete_rag_model`).
- `[ai_stream.go:MountStreamChat]`: Mounts `POST /api/stream_chat` on `*http.ServeMux` for SSE investigation streaming.
- `[hierarchy_methods.go:RegisterHierarchyMethods]`: Registers 13 folder/source/workspace lifecycle methods (`get_hierarchy`, `create_folder`, `update_folder`, `delete_folder`, `create_log_source`, `update_log_source`, `delete_log_source`, `move_source`, `get_workspace_sources`, `delete_workspace`, `purge_inactive_workspaces`, `get_time_boundaries`, `factory_reset`).
- `[logops_methods.go:RegisterLogOpsMethods]`: Registers 15 log operations, parser/fusion, SSH tail, trace, job, and distribution methods (`delete_logs`, `export_logs`, `get_sample_lines`, `update_source_parser`, `get_fusion_config`, `update_fusion_config`, `get_fused_logs`, `get_sample_logs`, `update_log_comment`, `read_file`, `start_ssh_tail`, `log_trace`, `cleanup_ingestion_jobs`, `get_ingestion_jobs`, `get_log_distribution`).
- `[settings_methods.go:RegisterSettingsMethods]`: Registers 12 settings, template, log stream, and temporal offset methods (`get_settings`, `update_settings`, `reset_workspace_settings`, `save_template`, `get_templates`, `delete_template`, `reset_templates`, `get_log_streams`, `create_log_stream`, `delete_log_stream`, `update_temporal_offsets`, `get_temporal_offsets`).

## Invariants
- `[registry.go:Registry.Register]`, `[registry.go:Registry.RegisterWithModel]`, `[app_methods.go:RegisterApp]`: Later registrations overwrite earlier entries by method name without mutex synchronization (registration is expected at startup before serving); `RegisterApp` overrides 14 stubbed methods and adds 8 Laya methods absent from `allMethods`.
- `[dispatch.go:Registry.Dispatch]`: Defaults empty `req.Params` to `"{}"`; unmarshals against `entry.model()` when non-nil (`CodeInvalidParams` `-32602` on mismatch) while passing raw/defaulted `json.RawMessage` to `entry.handler`; catches handler panics via `recover()` and returns `CodeInternalError` (`-32603`).
- `[http.go:NewHTTPHandler]`: Applies wildcard CORS headers (`applyCORS`) on `/rpc`; returns `204` for `OPTIONS`, `405` (`CodeInvalidRequest`) for non-`POST`, `500` (`CodeInternalError`) on read error or `!json.Valid`, `400` (`CodeInvalidRequest`) on unmarshal failure or empty method, and `200` for all dispatched JSON-RPC responses.
- `[stdio.go:RunStdio]`: Uses a `bufio.Scanner` with `64 KiB` initial and `64 MiB` max token capacity; skips blank lines; returns `CodeParseError` (`-32700`, `id: nil`) on invalid JSON or `CodeInvalidRequest` (`-32600`, preserving `generic["id"]`) on invalid envelope/empty method; writes one JSON line per non-blank request until EOF.
- `[ai_methods.go:sendAIMessage]`, `[ai_methods.go:prepareAISession]`, `[ai_methods.go:finalizeAISession]`, `[ai_stream.go:streamChatHandler]`, `[ai_stream.go:parseSendAIMessageBody]`: Defaults `Reasoning` to `true`, attaches `"workspace_id"` on `ctx`, injects contextual log summary in-memory onto the last loaded message without persisting it to `ai_messages`, drops that last history item before running `graph.Run`, extracts/strips `[[A2UI]]...[[/A2UI]]` tags (`strict: true` for RPC, `strict: false` for SSE), and always calls `finalizeAISession`; `streamChatHandler` accepts both `{"params": {...}}` and flat request JSON bodies and omits `"data: [DONE]\n\n"` if streaming failed or context canceled.
- `[ai_extra_methods.go:RegisterAIExtraMethods]`, `[hierarchy_methods.go:RegisterHierarchyMethods]`, `[logops_methods.go:RegisterLogOpsMethods]`, `[settings_methods.go:RegisterSettingsMethods]`: Validate typed request payloads via `appHandler`/`paramModels` where registered, skip `json.Unmarshal` on empty params for `get_rag_model_status`/`download_rag_model`/`delete_rag_model`, run `*ai.Extra` handlers with `context.Background()`, and manually decode/validate legacy flat-param methods (`save_template`, `get_templates`, `delete_template`, `reset_templates`, `update_temporal_offsets`).

## Side Effects
- `[registry.go:Registry.Register]`, `[registry.go:Registry.RegisterWithModel]`, `[methods.go:RegisterStubs]`, `[app_methods.go:RegisterApp]`, `[ai_methods.go:RegisterAI]`, `[ai_extra_methods.go:RegisterAIExtraMethods]`, `[hierarchy_methods.go:RegisterHierarchyMethods]`, `[logops_methods.go:RegisterLogOpsMethods]`, `[settings_methods.go:RegisterSettingsMethods]`: Mutate the `*Registry` method table at startup.
- `[http.go:NewHTTPHandler]`, `[http.go:ListenAndServe]`, `[ai_stream.go:MountStreamChat]`, `[ai_stream.go:streamChatHandler]`: Bind TCP HTTP listeners (`http.ListenAndServe`), register `/rpc` and `/api/stream_chat` on `*http.ServeMux`, and read HTTP requests / flush JSON or SSE responses.
- `[stdio.go:RunStdio]`: Reads lines from `io.Reader`, writes/flushes JSON-RPC lines to `io.Writer`, and logs I/O or scanner errors via `log.Printf`.
- `[ai_methods.go:prepareAISession]`, `[ai_methods.go:contextualLogSummary]`, `[ai_methods.go:finalizeAISession]`, `[ai_stream.go:streamChatHandler]`: Query/insert/update DuckDB (`ai_sessions`, `ai_messages`, `logs`), hydrate lines via `a.FastPath.GetLine`, and run external AI turns via `graph.Run` + `Provider` + `ToolRegistry`.
